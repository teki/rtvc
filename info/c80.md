# C80 Language Reference

C80 is a small C-like language for Z80 programs in rtvc. It is not ISO C.
This page documents **implemented** compiler behavior. Planned forms are listed
so later syntax is not mistaken for a parser bug.

The compiler lives in [`c80/`](../c80/) as the `rtvc-c80` crate. `cargo build`
in the repo root does not compile it. Use `cargo run -p rtvc-c80`. Compilation
takes in-memory source snapshots and returns an AST, located diagnostics, typed
IR, and assembled Z80. It does not read the filesystem or own UI state.

A walkthrough with compilable sources is the [C80 Tutorial](c80/tutorial.md).

## Implemented in E01–E04

### Lexical form

- Source is UTF-8. Spans are **byte offsets** (`start` inclusive, `end`
  exclusive) plus a line index for display (1-based line and byte column).
- Identifiers: ASCII letters, digits, and underscore; must start with a letter
  or `_`. They are case-sensitive.
- Keywords: `void`, `bool`, `u8`, `i8`, `u16`, `i16`, `str`, `ptr`, `true`,
  `false`, `pub`, `const`, `import`, `struct`, `if`, `else`, `while`, `for`,
  `do`, `return`, `break`, `continue`, `sizeof`, `asm`.
- Line comments `//` and non-nested block comments `/* ... */`.
- Decimal integers and hexadecimal integers with a `0x` or `0X` prefix.
  Canonical spelling is `0x` (for example `0xFE`).
- Character literals `'A'` and string literals `"hello"`.
- Escapes: `\n`, `\r`, `\t`, `\0`, `\\`, `\'`, `\"`, and `\xNN` (exactly two
  hex digits). Other escapes are errors. Non-ASCII bytes in literals are
  errors in this slice.

### Grammar (accepted)

```text
unit        := { item }
item        := import | struct | function | declaration
import      := "import" ident ";"
struct      := "struct" ident "{" { field } "}" ";"
field       := type ident [ "[" expr "]" ] ";"
function    := [ attr ] [ "pub" ] [ attr ] type ident "(" [ params ] ")" block
params      := param { "," param }
param       := type ident
declaration := [ "pub" ] [ "const" ] type ident [ "[" expr "]" ] [ "=" expr ] ";"
type        := "void" | "bool" | "u8" | "i8" | "u16" | "i16" | "str" | ident
             | "ptr" "<" type ">"
attr        := "@stackcall" | "@fastcall"

block       := "{" { stmt } "}"
stmt        := block
             | [ "const" ] type ident [ "=" expr ] ";"
             | "if" "(" expr ")" stmt [ "else" stmt ]
             | "while" "(" expr ")" stmt
             | "for" "(" [ decl-or-expr ] ";" [ expr ] ";" [ expr ] ")" stmt
             | "do" stmt "while" "(" expr ")" ";"
             | "return" [ expr ] ";"
             | "break" ";"
             | "continue" ";"
             | asm_stmt
             | expr ";"
asm_stmt    := "asm" [ "(" clause { "," clause } ")" ] "{" assembly-source "}"
clause      := "in:" register "=" expression
             | "out:" output-register "=" lvalue
             | "inout:" register "=" lvalue
             | "clobber:" name { "," name }
             | "stack:" nonnegative-integer-literal
register    := a | b | c | d | e | h | l | bc | de | hl
output-register := register | carry | zero
clobber-name := register | flags | memory

expr        := assign
assign      := or [ ( "=" | "+=" | "-=" | "&=" | "|=" | "^=" | "<<=" | ">>=" ) assign ]
or          := and { "||" and }
and         := bitor { "&&" bitor }
bitor       := bitxor { "|" bitxor }
bitxor      := bitand { "^" bitand }
bitand      := eq { "&" eq }
eq          := rel { ("==" | "!=") rel }
rel         := shift { ("<" | "<=" | ">" | ">=") shift }
shift       := add { ("<<" | ">>") add }
add         := prefix { ("+" | "-") prefix }
prefix      := ( "+" | "-" | "!" | "~" | "*" | "&" | "++" | "--" ) prefix
             | postfix
postfix     := primary { "(" args ")" | "[" expr "]" | "." ident | "->" ident | "::" ident | "++" | "--" }
primary     := ident | integer | character | string | "true" | "false"
             | "(" expr ")"
             | type "(" expr ")"          # conversion, e.g. u8(x)
             | "sizeof" "(" type ")"
             | "{" [ expr { "," expr } [ "," ] ] "}"
args        := [ expr { "," expr } ]
```

Operator precedence matches the language contract, weakest to strongest:
assignment; `||`; `&&`; `|`; `^`; `&`; `==`/`!=`; `<`/`<=`/`>`/`>=`; `<<`/`>>`;
`+`/`-`; prefix; postfix/call/index/member. Assignment and prefix are
right-associative; other binary operators are left-associative.

`+`/`-` bind **tighter** than shifts, unlike C. `a << b + c` is
`a << (b + c)`.

The parser recovers at `;`, `}`, and top-level declaration starters so a later
valid function can still be parsed after an incomplete one. Diagnostics have a
severity, stable code, message, and primary source span.

### Scalar semantics (E02)

Valid scalar programs produce typed control-flow IR (`CompilationResult.program`).
Any error leaves `program` as `None`; nothing is assembled.

- Types: `void`, `bool`, `u8`, `i8`, `u16`, `i16`. Storage is 1 byte for
  `bool`/`u8`/`i8` and 2 bytes for `u16`/`i16`. Signedness is interpretation,
  not a distinct machine layout.
- Integer operators require the **same** type after contextual literal typing.
  Mixed typed operands (for example `u8 + u16`) are errors. `+`/`-` wrap at
  width. `u8 x = 255 + 1` is 0.
- Untyped integer literals take an assignment/return/parameter/operand context
  if they fit. With no context, a literal-only subtree is `u16`, or `i16` if it
  contains a syntactic negative. `-32768` is a valid `i16`. `bool b = 1` is an
  error; use `bool(1)`.
- Casts type the argument independently, then convert: bit-preserving at the
  same width, low bits on narrow, sign/zero extend on widen. `bool(n)` is
  nonzero; `u8(true)` is 1.
- `sizeof(T)` is a `u16` byte count for complete scalar types. `sizeof(void)`
  is an error.
- Locals have no implicit init. A read must be assigned on every incoming path,
  including `if` without `else` and zero-trip `while`. Parameters are assigned.
  Globals without an initializer are zero. `const` needs a compile-time init.
- Shadowing inner blocks is allowed; duplicates in one scope are errors.
- Every reachable exit of a non-void function needs `return` with a value.
  Void functions may fall through (IR emits return). Direct and mutual
  recursion, including cross-unit call graphs, are errors.
- Conditions must be `bool`. Shift counts are `u8`.

### Register-leaf code (E03)

Straight-line functions with scalar arithmetic/bitwise ops, casts, locals, and
`return` are lowered to structured Z80 items, rendered, and assembled with
[`assemble_program`](../src/emulator/asm.rs) at origin `0x8000` unless
`CompileInput.origin` is set. Each instruction keeps a per-build ID and source
span; addresses come from the assembler, not from parsing disassembly text.

Default (register) ABI, F002:

- Word arguments take HL, then DE, then BC in declaration order among those
  arguments.
- Byte/bool arguments then take A, C, B, E, D, L, H, skipping halves reserved
  by the word assignment.
- Byte/bool results return in A; words return in HL.
- A signature that does not fit is a `cg-unsupported` error suggesting
  `@stackcall`; the compiler does not add hidden stack arguments.
- Tiny leaves emit no IX frame and no argument slots. `u8 id(u8 x) { return x; }`
  is `RET`. `u16 add(u16 a, u16 b) { return a + b; }` is `ADD HL,DE` then `RET`.

A bounded FakeBus/Z80 harness can load the assembled bytes, push a return
sentinel, and stop when PC reaches it. Exceeding the instruction or T-state
limit is a failure, not a successful halt. The harness reports extra stack
bytes below the function's entry SP.

### Control flow and globals (E04)

`if`/`else`, `while`, `break`, `continue`, comparisons, `&&`/`||`, and scalar
globals are lowered. Baseline lowering uses `JP`. Locals used across blocks
stay in registers; a simple counter loop has no per-iteration stack traffic and
no IX frame. Signed compares use a bias so overflow boundaries are correct.

Globals are placed in source order with functions (not collected into a
separate section). Each mutable global load or store is emitted; successive
reads of one global are not folded, and successive writes are not coalesced.

### Calls, spills, and `@stackcall` (E05)

Calls use the register ABI by default. `@stackcall` (before or after `pub`)
selects caller-cleaned right-to-left two-byte stack slots; `@fastcall` is an
optional alias for the default. Nested calls preserve live caller-saved values.
Argument moves that swap A and C (for example `f(x, y - x)`) park one byte in a
scratch register so the difference is not overwritten with `x`.
Tiny leaves stay frame-free. A function that needs spills or `@stackcall`
parameters uses a saved-IX frame: parameters at `IX+4`, locals/spills at
negative offsets that must fit a signed displacement. Stack bounds count the
frame plus the maximum call-site extra (argument slots + `CALL` + callee bound),
not the sum of sibling calls.

### Arrays, pointers, and strings (E06)

- `ptr<T>` is a 16-bit address. `T` may be `bool`, an integer, or another
  pointer; not `void`, `str`, or an array. `ptr<u8>(addr)` and `u16(pointer)`
  are explicit; `ptr<U>(ptr<T>)` reinterprets the same address.
- `&scalar` and `&array[index]` are supported. `&array`, address-of a
  constant, and address-of a string payload are rejected. Arrays do not decay;
  use `&array[0]`. Directly returning `&local` is a warning
  (`ty-return-local-addr`), not an error; the local lives in the IX frame for
  that call.
- Pointer ± integer scales by `sizeof(T)` and wraps in 16-bit address space.
  Equality/inequality are allowed; ordered pointer compares and pointer
  subtraction are not.
- Global arrays are one-dimensional, length 1..65535, scalar or complete
  struct elements, total size ≤ 65535. Syntax is `u8 positions[16]` (name
  then `[N]`). Locals, by-value aggregate arguments/returns, and whole-array
  assignment are rejected. Uninitialized global scalars/arrays/structs emit
  zeros in place. Constant indexes that are negative or past the length are
  errors; dynamic indexes are unchecked. `a[i] = v` stores through the
  element address. Compiler-generated address scaling uses shift-and-add,
  not source `*`.
- `str` globals own a length prefix plus payload and need a string-literal
  initializer (payload 0..255 bytes). `str` locals/parameters/returns are
  2-byte references. `sizeof(str)` is 2; owned-string metadata reports
  `1+payload`. `.len` is `u8`. `s[i]` reads payload at `ref+1+i`. Constant
  bounds are checked only when the length is known. Owned `str` globals and
  payloads are immutable. Anonymous literals are placed after the owning
  function without fallthrough.
- `sizeof(T)` is a `u16` for scalars, pointers, `str`, and named structs.
  `sizeof(void)` and `sizeof` of an array type are errors.
- Source order is still declaration order. A data-only unit keeps that layout.

### Units, manifests, and CLI (E07)

- `import other;` plus `other::name` looks up **public** symbols of unit
  `other`. Unqualified names stay local. Missing units, missing imports, and
  private cross-unit names are errors. `project` and `cpu` are reserved builtin
  namespaces and cannot be a unit or import.
- `pub const` has no storage. A constants-only unit needs no origin and emits
  no bytes. Units that emit bytes require an origin. Declaration order is
  preserved inside each unit; each emitting unit starts at its own `ORG`.
- Built-ins `project::stack_base`, `stack_size`, `stack_top`, and `stack_end`
  are compile-time `u16` values when representable. `stack_top` is
  `(base+size) modulo 65536`. If `stack_end` is 65536 it is not a C80 `u16`.
- Reservations occupy no bytes. Ranges may be adjacent but must not overlap or
  exceed 65536. Known stack use above `[stack].size` is an error; unknown ASM
  bounds warn and still produce code.
- Assembly units have no compiler prologue/epilogue. `@{unit::export}` and
  `@{project::...}` are substituted outside quotes and comments. Private ASM
  labels are namespaced; case-insensitive collisions in one unit are errors.
  Calling an ASM export from C80 is not a typed call.
- `compile_project` links C80 and ASM units in memory. The CLI is
  [`rtvc-c80`](../src/bin/rtvc_c80.rs):
  `rtvc-c80 build INPUT [--target TARGET] [--origin ADDRESS] [--no-optimize]
  [--emit-asm PATH] [--emit-segments PATH] [--emit-bin PATH]`. A `.c80` file uses its stem as
  the unit name and needs `--origin` if it emits bytes. A `.toml` manifest
  resolves paths from the manifest directory; `--origin` is invalid there.
  Segment output is `rtvc-asm-v1`. A TVC `[basic]` project includes the tokenized
  BASIC payload in that same TOML at `19EFH`. Raw binary requires a contiguous union and
  is not padded.

### Inline assembly (E08)

- `asm { ... }` is a statement. Without a header it conservatively clobbers
  AF/BC/DE/HL and memory. With `(clauses)` it uses explicit `in`/`out`/`inout`
  registers, flag outputs `carry`/`zero`, `clobber`, and `stack:N`. Header
  names are lowercase. A comma after `clobber` names starts a new clause when
  the next token is a clause keyword and colon.
- Width matches the register: bytes (including `bool`) for `a`..`l`; words,
  pointers, and `str` references for `bc`/`de`/`hl`. Flag outputs are `bool`
  and capture CF/ZF without inversion. Overlapping inputs or overlapping
  outputs are errors; an input may reuse an output register. A clobber that
  overlaps an output is an error; `flags` may coexist with `carry`/`zero`.
- Header expressions and destination addresses are evaluated left-to-right
  once before the body. `inout` reads the old value at that point. Outputs
  establish definite assignment; `inout` requires a prior assignment.
  Result registers and flags are captured before writeback. `bool` register
  outputs are normalized to 0/1.
- The body is raw helper-assembler text (including `$` and `;` comments).
  Local labels are namespaced per block. Allowed: instructions, local labels,
  local EQU, balanced PUSH/POP, returning CALL/RST. Rejected: RET/RETI/RETN,
  jumps out of the block, indirect jumps, ORG/BASIC_START, DB/DW/DS, SP
  adjustments, and IX/IY/EXX/EX AF writes other than balanced PUSH/POP IX/IY.
  `stack:N` is a trusted extra-stack bound; a visible peak above N is an
  error. CALL/RST without `stack:N` warn (`ln-stack`) and leave usage unknown.
  LDIR with BC=0 is raw Z80 (65536 copies), not skipped. No ROM wrappers.

### CPU builtins

- `cpu::in(u8 port) -> u8`, `cpu::out(u8 port, u8 value)`, `cpu::di()`,
  `cpu::ei()`, and `cpu::ldir(hl, de, bc)` are compiler intrinsics in the
  reserved `cpu` namespace. They cannot be imported or used as function
  values. Bare names `in` / `out` / `di` / `ei` / `ldir` are not reserved;
  `in:` and `out:` remain inline-assembly operand keywords.
- Each `cpu::in` / `cpu::out` transfers one byte. Fitting literals such as
  `cpu::out(0x06, 0x80)` and typed `u8` arguments are accepted; a typed `u16`
  needs `u8(...)`. Wrong arity/types, out-of-range literals, and using a
  void result as a value are errors. Arguments are evaluated once,
  left-to-right. Every evaluated input or output is observable, including a
  discarded `cpu::in` or repeated identical writes. I/O is never folded, merged,
  eliminated, speculated, or hoisted; short-circuited expressions perform
  none.
- On `target = "tvc"` (and `--target tvc` for a lone `.c80` file), a constant
  port lowers to `IN A,(n)` / `OUT (n),A`. Dynamic TVC ports use `IN A,(C)` /
  `OUT (C),A` without forcing `B`. `generic-z80` and `zx82` zero-extend the
  port to `BC` and always use the `(C)` forms. `compile_source` defaults to
  `generic-z80`.
- `cpu::di()` and `cpu::ei()` take no arguments, return void, and emit `DI` /
  `EI`. They are never folded or removed.
- `cpu::ldir(hl, de, bc)` is raw Z80 `LDIR`: **HL is source**, **DE is dest**,
  **BC is count** (opposite of `memcpy`). HL and DE accept a pointer or
  `u16`/`i16` (not `str`); BC is `u16`. The call is inline (no `CALL`). BC=0
  copies 65536 bytes, not a skip. It clobbers HL, DE, BC, flags, and destination
  memory.

### Listing, timing, and stack reports (E09)

- Successful results expose `CompilationResult::map()`: listing entries, symbols,
  no-code spans, stack provenance, and a build identity (crate version, origin,
  source names, and a hash of the owned snapshots). Failed compiles keep
  `code: None` and `map(): None`; they do not hand back a loadable program.
- Each listing entry has address, bytes, text, `StaticTiming` (`Exact`,
  `Branch` taken/not-taken, `Repeating` for LDIR-class block repeats, or
  `Unknown`), kind (instruction vs data), and spans. Prologues, ABI copies,
  IX cleanup, and fallthrough jumps are `synthetic`. Inline `asm` bodies map
  through the statement span. Selection prefers the smallest expression span
  containing a source offset, then the enclosing statement.
- Instruction timing comes from existing disassembler metadata on the final
  bytes. `SpanCost` sums local T-states but is not `complete` when the span
  contains a call, loop, repeating instruction, or unknown timing. There is
  no `--emit-map` file; maps stay in-process.
- Function stack reports are `proven` (C80 lowering only), `declared` (trusted
  `stack:N` or ASM `stack_extra`), or `unknown` (CALL/RST without a bound).
  Unused local declarations that emit no instructions are recorded as
  no-code so they are not treated as executable breakpoints.

### Structs, loops, and assignment (E10)

Packed structs are declaration-order, no padding. `struct Sprite { u8 x; u8 y;
u16 bitmap; bool visible; }` is 5 bytes. Fields may be scalars, pointers,
nested structs, or fixed arrays of those. Empty structs and recursive
by-value layouts are errors; `ptr<Self>` is allowed. `str` fields are not.
`.` and `->` produce ordinary lvalues. `&field` and `&array[index]` are
allowed; `&array` is not. Static brace initializers are positional, may nest,
and omit trailing elements (zero-filled). Excess initializers are errors.

`for (init; cond; update)`: empty `cond` is true; `continue` runs `update`
then the condition. `do { body } while (cond);` always runs the body once;
`continue` goes to the condition.

Compound assignment evaluates the destination address once, reads, evaluates
the RHS, and writes once; the result is the stored value. Accepted operators:
`+= -= &= |= ^= <<= >>=`. Pointers allow only `+=`/`-=`, stepping one
element. Prefix `++`/`--` returns the new value; postfix returns the old.
`*=` `/` `%` and their compounds stay rejected.

### Mixed BASIC/C80 projects (E11)

A TVC manifest may include one `[basic]` region:

```toml
target = "tvc"
[basic]
path = "src/main.bas"
```

`[basic]` is rejected on other targets. BASIC is always stored at `19EFH`
(TVC BASIC 1.2 `PROGRAM`). Its size is the tokenized payload, including the
`00H` terminator. That half-open range `[19EFH, 19EFH+payload)` must not
overlap C80/ASM output, `[stack]`, or `[[reserve]]` entries (ranges may
touch). `origin` and `size` in `[basic]` are errors. C80 may read
`project::basic_base` (`19EFH`). `project::basic_size`, `basic_end`,
`basic_himem`, and `basic_program_size` exist only after tokenization and are
not C80 values. `basic_program_size` is exported on the segment TOML.

BASIC `@{unit::export}` and `@{project::symbol}` markers are replaced with
unsigned decimal integers after C80 assembly. Markers inside quoted strings,
`REM`/`!` tails, and `DATA` fields stay literal; an unquoted `DATA` colon
resumes substitution. Unknown or malformed active markers are errors.

The compiler does not write interpreter state or generate USR wrappers. A
mixed `--emit-segments` TOML is the loadable image: C80/ASM segments plus the
tokenized BASIC payload at `19EFH`, with `project::basic_base` and
`project::basic_program_size` in `[symbols]`. Mixed `--emit-asm` appends
`ORG`/`DB` for those BASIC bytes. `--emit-bin` still requires a contiguous
union and will reject a `3000H` C80 image plus a short BASIC stub at `19EFH`.
`rtvc-tocas` flattens a mixed `rtvc-asm-v1` TOML into one cassette when the
first segment is tokenized BASIC at `19EFH` (gaps zero-filled through the
highest emitted end, exclusive end at most `C000H`). The tutorial mixed,
`tvc-usr`, and pong examples use that profile; `compile.sh` writes sibling
`.cas` files. Cassette examples inject the `.cas` into a booted machine.
`rtvc -i` types `RUN` when the CAS autostart byte is set (`rtvc-tocas` TOML
output). Example call: `LET R=USR(@{math::echo},42)`
with `@fastcall pub i16 echo(i16 value)` returning `value` in `HL`.

### Code quality (E12)

`compile_source`, `compile_project`, and `rtvc-c80` optimize by default
(`CompileInput.optimize = true`). The pass is provenance-preserving:

- identity `LD r,r` and unconditional jumps to the next emitted label are
  dropped;
- after layout, forward conditional `JP cc` become `JR cc` when the final
  displacement fits `-128..=127` (`cc` is only `Z`, `NZ`, `C`, `NC`);
  backward and unconditional jumps stay `JP` so taken loop edges do not pay
  the extra JR T-states;
- `JP cc, then; JP else` collapses to `JP !cc, else` when `then` is the next
  block (not-taken sequential path);
- successive stores and polling loads of mutable memory are not coalesced or
  CSE'd;
- compiler-generated address scaling stays shift-and-add;
- `DJNZ` is not emitted: a `while (n != 0)` with `n == 0` must iterate zero
  times, while `DJNZ` with `B == 0` would wrap to 256.

Pass `optimize: false` or `rtvc-c80 build … --no-optimize` for baseline
lowering (all `JP`, no fallthrough removal). Far branches stay `JP`. Listing
maps still cover every emitted byte; removed compiler-private jumps do not
invent executable source breakpoints.

A representative compile-latency fixture (packed struct, pointer walk, `for`,
nested `if`) is compiled repeatedly in the compiler test suite.

The compiler is the `rtvc-c80` crate (`c80/`). Native desktop, `wasm-full`, and
lightweight `wasm` do not include it. There is no editor and no `--emit-map`
CLI flag; `CompilationResult::map()` is in-process.

## Explicitly unsupported in this slice

These tokens are recognized so they are not silently treated as identifiers.
They produce a located `parse-unsupported` (or similar) diagnostic:

- `*`, `/`, `%` as binary operators and `*=` `/=` `%=`

Later increments add the accepted forms from the design; this list is not a
frozen language limitation.

## Library entry

```rust
rtvc_c80::compile_source("unit.c80", source)
```

or `compile(CompileInput { files, origin, optimize, target })` for several in-memory snapshots
in one namespace, or `rtvc_c80::project::compile_project(manifest, units,
basic_source)` for a multi-unit manifest (`compile_project_opt` to disable
optimization). The result owns source text,
diagnostics, parsed units, optional typed IR, optional assembled code, and
optional tokenized BASIC.

The host CLI is `rtvc-c80 build …` as described under E07. `--no-optimize`
selects baseline lowering.
