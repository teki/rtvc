# rtvc

Language: [English](README.md) | [Magyar](README.hu.md)

`rtvc` is a Rust emulator for the Videoton TV Computer (TVC). It targets a usable native desktop emulator today, with shared core code for lightweight WebAssembly snapshot playback.

Try the web demo: [teki.one/rtvc](http://teki.one/rtvc/).

The project is still in active development. CPU execution, TVC memory mapping, keyboard input, video output, cassette loading, HBF/VT-DOS disk support, and native snapshots are implemented, but hardware accuracy work is ongoing.

## About the TVC

The Videoton TV Computer, usually shortened to TVC, was a Hungarian 8-bit home and school computer produced by Videoton in the second half of the 1980s. It was based on a licensed design related to the Enterprise line and was adapted for Hungarian educational use.

The machine used a Z80 CPU clocked at 3.125 MHz and was sold mainly in three variants: 32K, 64K, and 64K+. The 64K+ model added more video memory and a newer BASIC 2.2 ROM. The built-in TVC OS and BASIC lived in ROM; cassette storage was supported by the base system, while UPM and VT-DOS provided more capable disk-oriented environments.

Unlike many contemporary home computers, the TVC did not have a separate text-only display mode. Text was drawn through the graphics system, with modes for 512x240 in 2 colors, 256x240 in 4 colors, and 128x240 in 16 colors. Video output was generated by a 6845 CRTC. Sound was a single programmable channel derived from the system clock, with 16 volume levels and a 4-bit D/A mode when the frequency divider was disabled.

The TVC was designed to be expandable. It had cassette, RGB, TV, printer, joystick, cartridge, and upper expansion connectors; common expansions included memory, floppy, serial, and EPROM programmer cards. Around 12,000 machines were sold, mostly to schools, before production ended after only a few years.

Source: [VIDEOTON TVC historical overview](http://tvc.hu/html/tvc_attekintes.html) (Hungarian).

## Features

- Z80 CPU emulation with FUSE and ZEX test harnesses.
- TVC 64K and 64K+ machine variants.
- ROM 1.2 and ROM 2.2 machine selections, with optional VT-DOS/HBF extension.
- MC6845-based TVC video output with fast-frame and interleaved rendering modes.
- TVC keyboard matrix input through the native egui UI.
- CAS cassette playback/loading and DSK disk image support.
- Native snapshot save/load using `.rtvcsnap` and `.rtvcsnap.zip`.
- Static web snapshot bundle generation for browser-hosted demos.

## Download

Windows release archives include `rtvc.exe`, ROM files, bundled programs, and a `web/` snapshot player. Extract the zip and run `rtvc.exe` for the native emulator.

To use the web player, copy a compressed snapshot into `web/snapshot.rtvcsnap.zip`, serve the `web/` directory with any static web server, and open it in a browser:

```bash
cd web
python -m http.server 8000
```

## Run the Native Emulator

```bash
cargo run --bin rtvc
```

Start directly from a snapshot:

```bash
cargo run --bin rtvc -- snapshots/load_tape.rtvcsnap.zip
```

Place ROM files in `roms/` before running. The native UI currently supports these machine selections:

- `64k+ 1.2, VT-DOS`
- `64k+ 2.2, VT-DOS`
- `64k  1.2`
- `64k+ 1.2`
- `64k+ 2.2`

Common ROM filenames used by the project:

- `TVC12_D3.64K`
- `TVC12_D4.64K`
- `TVC12_D7.64K`
- `TVC22_D4.64K`
- `TVC22_D6.64K`
- `TVC22_D7.64K`
- `C_TVCDOS.128`
- `D_TVCDOS.128`
- `C_DOS12.128`
- `D_DOS12.128`

Optional program archives and media files can go in `progs/`.

## Supported Files

| File type | Purpose |
| --- | --- |
| `.cas` | TVC cassette image. |
| `.dsk` | Floppy disk image for HBF/VT-DOS. |
| `.zip` | Program archive containing a `.cas` or `.dsk`. |
| `.rtvcsnap` | Raw rtvc snapshot. |
| `.rtvcsnap.zip` | Compressed rtvc snapshot. |

## Native Snapshots

The native GUI has snapshot buttons:

- `Save Snapshot` writes a compressed `.rtvcsnap.zip` file by default.
- `Load Snapshot` reads either `.rtvcsnap.zip` or raw `.rtvcsnap` files.
- The native app also accepts an optional snapshot path as its first command-line argument.
- `Save Screenshot` writes the current TVC framebuffer as a 4:3 PNG (`768x576`).

Compressed snapshots are ordinary zip files containing one `snapshot.rtvcsnap` entry.

## Contributing

Issues and pull requests are welcome. Emulator accuracy reports are most useful when they include a small reproduction: the machine type, media file, snapshot, command typed on the TVC, and any relevant port or interrupt logs.

Please keep emulator behavior changes covered by focused tests where practical, and update the documentation in `info/` when changing core architecture, snapshot format, media handling, or build workflows.
